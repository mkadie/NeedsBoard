# Initial Needs Word List

> **Updated 2026-05-30:** This document was the original vocabulary list for Moana — the special-needs child the project was first built for — and identified six basic needs she did not currently communicate (the trampoline was the one that brought the author the most joy). The vocabulary has since been generalized into the `.menu` file system, allowing each device to be customized for its user.

---

## Status today

Vocabulary now lives in the [`menus/`](../menus/) directory as `.menu` files. The starting menu for a new device is `base.menu`. See [`menu_system.md`](../menu_system.md) for the file-format reference, and [`GUIDE_FOR_TEACHERS.md`](../GUIDE_FOR_TEACHERS.md) for how to add new pictures and sounds.

### Original Moana vocabulary, in short

The original list identified six basic needs Moana did not currently communicate. The one that brought the most joy in the design brief was **trampoline** — she apparently loved playing on it. The other five were the other immediate-needs categories captured in the original `.docx` (preserved below).

## Original document (Microsoft Word `.docx`, 2025)

The original word list was a Microsoft Word file uploaded to Google Drive. It cannot be auto-exported through the Google Docs API because it's stored as a native `.docx`, not a native Google Doc.

To preserve the original list verbatim:

1. Open the original at <https://docs.google.com/document/d/161QIsjfWnC853IrFSagrh-y-rKC1VBlQ/edit?usp=sharing> in a browser.
2. **File → Download → Plain Text (.txt)** *or* **File → Download → Markdown (.md)** if available.
3. Paste the contents below the marker line at the bottom of this file.

Until that snapshot is captured, this file holds the *summary* of the original (six basic needs, trampoline as the central example, used as the seed vocabulary for Moana's first device). The live vocabulary is the `.menu` files in the repo.
