# Help Wanted

This is an open-source project to help individuals with special needs communicate.
Contributions of all kinds are welcome!

## Ways to Contribute

### Software
- CircuitPython development
- Menu system enhancements
- New device variant support
- Testing on different hardware
- Bug fixes

### Hardware
- 3D printed enclosure designs
- PCB design for custom boards
- Power management improvements
- New input methods (switch access, eye tracking)

### Content
- Symbol/icon/emoji design for pre-literate users
- Sound file recording in different languages
- Combinational symbol systems (liquid + brown = chocolate milk)
- Menu templates for common vocabulary sets

### Special Needs Expertise
- AAC best practices
- Vocabulary selection guidance
- User testing with individuals
- Training materials for teachers/parents

### Other
- Documentation and tutorials
- Web interface for menu editing
- Translation to other languages
- Finding individuals with unaddressed special needs

## Getting Started

1. Fork the repo
2. Check [SETUP.md](SETUP.md) to get a device running
3. See [NOTES.md](NOTES.md) for the development roadmap
4. Open an issue or pull request

All skill levels welcome. Even small contributions help!
